Visão de cores

01

Seletores

Selecionam elementos específicos para aplicar estilo de forma precisa.

button:hover {
  color: #165b45;
}
02

Propriedades

Definem aparência, espaço, cor, alinhamento e comportamento dos elementos.

padding: 16px;
background: #f2ede2;
03

Acessibilidade

Contraste, foco e clareza ajudam a manter a interface legível para todos.

button:focus-visible {
  outline: 3px solid #17211d;
}
04

Layout

Grid, flexbox e espaçamento organizam o conteúdo de forma visualmente equilibrada.

.container {
  display: grid;
  gap: 24px;
}

Aprender CSS fica mais simples quando a estrutura e a leitura são claras.
